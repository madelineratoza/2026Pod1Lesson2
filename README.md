# 🌱 ReproRehab: Introduction to R

### Lesson 2 · Getting Started with Data

In Lesson 2, we move from learning the RStudio environment to actually working with a small dataset.

### In this lesson

We will practice:

* 📦 Creating and working with objects
* 👀 Using the RStudio Environment
* 🧰 Understanding packages
* 📂 Importing a CSV dataset
* 🔢 Performing simple calculations
* 🔎 Exploring and summarizing data

### Practice dataset

This lesson uses a small **synthetic rehabilitation study dataset** created specifically for practice. No real participant data are included.
